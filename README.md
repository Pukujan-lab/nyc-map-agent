# NYC Block Check

An AI chat plus a 3D map of NYC street life: 311 noise complaints and motor vehicle crashes, block by block and neighborhood by neighborhood.

The context pack for the app builder is in [`context/`](context/):

- [`context/BRIEF.md`](context/BRIEF.md) covers the product, users, and demo story
- [`context/FEATURES.md`](context/FEATURES.md) lists each feature with its acceptance checks and build order
- [`context/DATA_APIS.md`](context/DATA_APIS.md) lists the data endpoints, fields, and example queries
- [`context/CHAT_TOOLS.md`](context/CHAT_TOOLS.md) defines the actions the chat can take and example questions
